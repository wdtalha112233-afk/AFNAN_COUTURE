AFNAN COUTURE — Store Prototype
Includes:
- Product catalog
- Cart
- Cash-on-delivery checkout
- Order number
- Basic local admin/orders view

IMPORTANT:
This is a functional front-end prototype. Orders are stored in the browser (localStorage), so it is NOT suitable for real production orders yet.
For production, the next build should add a secure backend/database, real customer accounts, server-side order storage, admin authentication, inventory, and later an online payment gateway.

Language switch added: English / العربية with RTL support.
